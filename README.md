## Цель работы

Освоить запуск Node.js-приложений, установку и использование Express, создание HTTP-маршрутов, обработку параметров запроса, а также подключение манифеста и Service Worker для работы приложения в офлайн-режиме.

## Что реализовано

- Express-сервер отдаёт HTML, CSS, JavaScript и файлы PWA.
- `GET /` — главная страница с генератором паролей.
- `GET /about` — страница с описанием работы.
- `GET /api/status` — JSON-ответ о состоянии сервера.
- `GET /api/password` — генерация пароля с параметрами `length` и `includeSymbols`.
- `GET /api/password/:length` — дополнительный пример параметра маршрута Express (`req.params`).
- Длина пароля по умолчанию — 12; допустимый диапазон — от 1 до 64.
- `includeSymbols` по умолчанию равен `true`; значение `false` исключает специальные символы.
- Для недопустимой длины API отвечает кодом HTTP `400`.
- `manifest.json`, иконки и Service Worker обеспечивают установку и кеширование оболочки PWA.
- При отсутствии сети генератор создаёт пароль на устройстве с помощью Web Crypto API.

## Установка и запуск

Требуется Node.js (рекомендуется версия LTS) и npm.

1. Откройте терминал в папке проекта.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сервер:

   ```bash
   npm start
   ```

4. Откройте в браузере `http://localhost:3000`.
5. Чтобы завершить работу сервера, нажмите `Ctrl+C` в терминале.

Для перезапуска сервера при изменении файлов можно использовать `npm run dev`.

## Проверка API

| Запрос | Ожидаемый результат |
| --- | --- |
| `GET /api/status` | JSON со статусом `ok` |
| `GET /api/password` | Пароль длиной 12 символов по умолчанию |
| `GET /api/password?length=16&includeSymbols=true` | Пароль длиной 16 символов со специальными символами в наборе |
| `GET /api/password?length=24&includeSymbols=false` | Пароль длиной 24 символа без специальных символов |
| `GET /api/password/16?includeSymbols=false` | Пример использования параметра пути `req.params.length` |
| `GET /api/password?length=0` | HTTP 400 с JSON-описанием ошибки |
| `GET /api/password?length=65` | HTTP 400 с JSON-описанием ошибки |

Примеры можно открывать в адресной строке браузера или отправлять через `curl`.

## Проверка PWA и офлайн-режима

1. Откройте сайт через `http://localhost:3000` и обновите страницу, чтобы Service Worker установился и закешировал файлы.
2. В Chrome или Edge откройте инструменты разработчика (F12) → **Application** → **Service Workers**. Проверьте регистрацию Service Worker.
3. В **Application → Manifest** проверьте имя приложения и иконки. Для установки используйте команду браузера «Установить приложение», если она доступна.
4. В инструментах разработчика включите **Network → Offline** либо отключите сеть и обновите страницу.
5. Главная страница должна загрузиться из кеша. Генератор в офлайн-режиме использует Web Crypto API в браузере. API-маршруты при этом требуют работающий сервер.

> Для проверки PWA важно заходить по `localhost` или по HTTPS. Открытие HTML-файла напрямую через `file://` не подходит для проверки Service Worker.
